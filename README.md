# Aniversário da Ayarla — confirmação de presença

Site na Netlify com banco Netlify Blobs.

- `/` — convidados confirmam presença (sem login)
- `/admin` — painel da organizadora (senha criada no primeiro acesso)
- `/portaria` — conferência na entrada (código gerado no admin)

Publicação: Netlify → Add new site → Import from GitHub → este repositório. Nenhuma configuração extra.
Esqueceu a senha de admin? Netlify → Blobs → store `aniversario-ayarla` → apague a chave `auth` e crie de novo em /admin.
